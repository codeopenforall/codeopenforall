# Irfan Ali Khan

**PhD candidate, Computer Science — University of Missouri–Kansas City**
Rust security · LLM-based program analysis · graph neural networks · enterprise software architecture

I build machine-learning and LLM systems that find and fix security vulnerabilities in code. My dissertation work targets Rust: detecting vulnerabilities with heterogeneous GNNs and transfer learning, generating validated vulnerability datasets with LLMs, and translating unsafe C into secure Rust. Before the PhD I spent eight years as a Java architect, most recently leading development of a national-scale online payment platform at PTCL.
